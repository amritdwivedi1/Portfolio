BCA MAJOR PROJECT • PUBLISHED RESEARCH PAPER

HerSentinel — An Intelligent Companion for Women's Safety

Stack: React Native, Node.js, HTTPS, JWT, Motion Sensors

System Overview

HerSentinel is a safety platform engineered to reduce response times during high-distress emergency situations. Built as a mobile client paired with an event-driven server backend, the system allows women in danger to transmit instant SOS signals to guardians and law enforcement even when unable to manually interact with their device screen.

Key System Features

  • >
    SOS Alerts to Guardians: Instant multi-channel alert signals dispatched to registered emergency contacts.
  • >
    Motion-Sensor Distress Triggers: Accelerometer and gyroscope algorithms detect violent shakes or sudden falls, triggering emergency routines without opening the app interface.
  • >
    Voice-Command Activation: Hands-free hotword recognition for emergency activation when physical access is restricted.
  • >
    Real-Time Location Sharing: Encrypted GPS telemetry streaming continuously to guardian dashboards.
  • >
    Secure End-to-End Auth: Hardened server communication utilizing HTTPS TLS encryption and JSON Web Tokens (JWT).

TECHNOLOGY STACK:

React Native Node.js HTTPS JWT Security REST APIs Motion Sensor Telemetry GPS Tracking
