HerSentinel

An intelligent companion for women's safety — built as a BCA final-year major project and later co-authored into a published research paper.

// overview

HerSentinel is a mobile safety application built to give users fast, reliable ways to reach help when it matters. The app combines manual and automatic triggers with real-time location sharing, so a guardian is always in the loop.

The project was built together with a classmate as our BCA final-year major project, and later co-authored into a peer-reviewed research paper with faculty from the Department of Computer Applications, Delhi Technical Campus.

// features

  • ✓ SOS alerts sent instantly to registered guardians
  • ✓ Motion-sensor triggers that detect distress without needing to open the app
  • ✓ Voice-command activation for hands-free emergencies
  • ✓ Real-time location sharing with guardians
  • ✓ Secure communication and authentication via HTTPS and JWT

React Native Node.js HTTPS JWT
